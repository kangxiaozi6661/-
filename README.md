# 额度肥嘟嘟 · Codex Quota Pet

一个提示 Codex 剩余额度的 Windows 桌面宠物，支持五档胖瘦、点击语音和额度详情。

## 下载与安装

前往 [v0.1.2 发布页面](https://github.com/kangxiaozi6661/-/releases/tag/v0.1.2)，在 Assets 中下载完整发布包 ZIP。

解压后，运行 `Release附件/codex-quota-pet-0.1.2-x64-setup.exe`。需要本机 Codex 已使用 ChatGPT 账号登录。

压缩包同时包含 `codex-quota-pet/` 源码、可选 Codex 插件、校验文件及使用与发布说明。详细使用方法见包内 `codex-quota-pet/README.md`。

当前版本为 Windows x64 预览版。代码采用 MIT 许可；图片与配音的权利说明见包内 `THIRD_PARTY_NOTICES.md`。
